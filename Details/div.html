<div> Tag

The <div> tag is a block-level container used to group HTML elements. It takes the full width of the page and starts on a new line.

Uses of <div>

  • Creating layout sections (header, footer, sidebar, etc.)
  • Grouping content for styling with CSS
  • Wrapping multiple elements together

Basic Example

<div>
    This is a simple div block.
</div>

With Styling

<div style="background: lightblue; padding: 20px; border-radius: 8px;">
    Styled DIV block
</div>

DIV Layout Example

<div style="display: flex;">
    <div style="width: 50%; background: #ddd; padding: 10px">Left Section</div>
    <div style="width: 50%; background: #bbb; padding: 10px">Right Section</div>
</div>
