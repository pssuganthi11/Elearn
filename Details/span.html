<span> Tag

The <span> tag is an inline container used to highlight or style specific parts of text. It does NOT start on a new line and takes only the required width.

Uses of <span>

  • Highlighting text inside a paragraph
  • Applying inline styles
  • Targeting a small portion of text with CSS/JS

Basic Example

<p>
    This is a <span>highlighted</span> word.
</p>

With CSS Styling

<span style="color: red; font-weight: bold;">
    Important text
</span>

Inline Text Example

<p>
    Price: <span style="color: green;">$999</span>
</p>
