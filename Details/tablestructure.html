Table Tags

HTML tables are used to display structured data in rows and columns.

1. <table>

The main container for all table elements.

<table>
    ...
</table>

2. <tr> – Table Row

Defines a row inside a table.

<tr>
    <td>Row data</td>
</tr>

3. <td> – Table Data Cell

A standard data cell in a table.

<td>Cell content</td>

4. <th> – Table Header Cell

Defines a heading cell (usually bold + centered).

<th>Header</th>

5. <thead>

Groups the header content of a table.

<thead>
    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>
</thead>

6. <tbody>

Groups the main body content of a table.

<tbody>
    <tr><td>John</td><td>22</td></tr>
</tbody>

7. <tfoot>

Defines footer rows.

<tfoot>
    <tr><td colspan="2">End of table</td></tr>
</tfoot>

8. <caption>

Title for the table, placed at the top.

<caption>Student Data</caption>

9. <colgroup>

Groups one or more columns for styling.

<colgroup>
    <col span="1" style="background:#ddd">
</colgroup>

10. <col>

Defines column-specific styles.

<col style="background:yellow">
