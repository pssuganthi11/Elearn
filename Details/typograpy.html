Typography Tags

Typography tags control text appearance, importance, and structure.

1. Heading Tags (h1–h6)

Used for titles and subheadings. h1 is the most important, h6 is the least.

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

2. <p> Paragraph

Displays standard text blocks.

<p>This is a paragraph.</p>

3. <br> Line Break

Breaks the line without starting a new paragraph.

Hello<br>World

4. <hr> Horizontal Line

Creates a thematic break.

<hr>

5. <strong> and <b>

strong: bold with importance.

b: visual bold only.

<strong>Important</strong>
<b>Bold Text</b>

6. <em> and <i>

em: emphasis (screen readers stress it)

i: italic styling only

<em>Emphasized</em>
<i>Italic</i>

7. <u> Underline

<u>Underlined text</u>

8. <mark> Highlight

<mark>Highlighted text</mark>

9. <small> Small text

<small>Small note</small>

10. <del> Deleted text

<del>Deleted</del>

11. <ins> Inserted (underlined) text

<ins>Inserted</ins>

12. <sup> Superscript

X<sup>2</sup>

13. <sub> Subscript

H<sub>2</sub>O

14. <blockquote> Quoted text

<blockquote>A long quote.</blockquote>

15. <pre> Preformatted text

<pre>
    Text stays
        exactly as typed
</pre>

16. <code> Code snippet

<code>console.log("Hello")</code>
