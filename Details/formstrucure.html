HTML Form Tags

This page covers all common HTML form tags with examples and outputs.

<form> – Basic Form Structure

The <form> tag is used to collect user input.

Important attributes:

  • action = where form submits
  • method = GET/POST
<form action="" method="post">
    <input type="text" placeholder="Enter Name">
    <button type="submit">Submit</button>
</form>


<label> and <input> Tags

The <label> tag improves accessibility.

<input> supports many types:

  • text
  • password
  • email
  • number
  • date
  • color
  • file
  • checkbox
  • radio
  • range
  • search
  • url
<label for="fname">Name:</label>
<input type="text" id="fname">

<select> – Dropdown Menu

<optgroup> – Grouped Options

    <option>India</option>
    <option>Japan</option>
  </optgroup>
  <optgroup label="Europe">
    <option>France</option>

</select>
