List Tags in HTML

HTML provides tags to create ordered, unordered, and description lists.

1. <ul> – Unordered List

Displays items with bullets. Common for menus or general lists.

<ul>
    <li>Item 1</li>
    <li>Item 2</li>
</ul>

2. <ol> – Ordered List

Displays items with numbers or letters.

<ol>
    <li>First</li>
    <li>Second</li>
</ol>

3. <li> – List Item

Represents an item inside <ul> or <ol>.

<li>List item</li>

4. Description List: <dl>, <dt>, <dd>

Used for definitions or name/value pairs.

<dl>
    <dt>HTML</dt>
    <dd>HyperText Markup Language</dd>
</dl>

5. Nested Lists

Lists can be placed inside other lists.

<ul>
    <li>Parent Item
        <ul>
            <li>Child Item</li>
        </ul>
    </li>
</ul>

6. list-style Properties (CSS)

Controls how list markers look.

ul {
    list-style-type: square;
}

ol {
    list-style-type: upper-roman;
}
