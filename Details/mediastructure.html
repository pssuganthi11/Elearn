Media Tags

HTML provides media tags to display and control audio, video, and images.

1. <img> (Image)

Displays an image on the page.

<img src="photo.jpg" alt="Description">

2. <audio>

Embeds audio with controls.

<audio controls>
    <source src="sound.mp3" type="audio/mpeg">
</audio>

3. <video>

Embeds a video player.

<video width="320" controls>
    <source src="movie.mp4" type="video/mp4">
</video>

4. <source>

Defines multiple media file sources for audio/video.

<video controls>
    <source src="movie.mp4" type="video/mp4">
    <source src="movie.webm" type="video/webm">
</video>

5. <figure> + <figcaption>

Used for images or media with captions.

<figure>
    <img src="img.jpg" alt="">
    <figcaption>Caption text</figcaption>
</figure>

6. <picture>

Allows responsive images for different screen sizes.

<picture>
    <source srcset="large.jpg" media="(min-width: 800px)">
    <source srcset="small.jpg" media="(max-width: 799px)">
    <img src="default.jpg" alt="Responsive">
</picture>

7. <track>

Adds subtitles or captions to videos.

<video controls>
    <source src="video.mp4">
    <track src="subtitles.vtt" kind="subtitles" srclang="en" label="English">
</video>
