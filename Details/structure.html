HTML Structure Tags Explained

1. <!DOCTYPE html>

Defines the HTML version. For HTML5, always use <!DOCTYPE html>.

2. <html>

The root element that contains the entire webpage.

3. <head>

Contains metadata, links, scripts, fonts, and the page title.

4. <title>

Defines the page name shown on the browser tab.

5. <meta>

Provides metadata such as charset, description, keywords.

6. <link>

Links external files like CSS, fonts, icons.

7. <body>

Contains all visible page content.



Complete Example Code:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Webpage</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>Welcome!</h1>
    <p>This is sample content.</p>
</body>
</html>
