Container & Layout Tags

Container tags group content together for layout, styling, or semantics.

1. <div> (Block Container)

Div is a block-level container used for layout or grouping elements.

<div>
    Block container
</div>

2. <span> (Inline Container)

Inline container used to wrap small pieces of text.

<span>Inline text</span>

3. <section>

Represents a standalone themed section (ex: About, Services).

<section>
    <h2>About Us</h2>
</section>

4. <article>

Independent self-contained content (blog post, news, card).

<article>
    <h2>Blog Post</h2>
</article>

5. <main>

Main content area of a page. Only one per document.

<main>
    Main website content
</main>

6. <header>

Page or section header (logo, nav, title).

<header>
    <h1>Site Title</h1>
</header>

7. <footer>

Bottom part of page or section (copyright, links).

<footer>
    © 2025 My Website
</footer>

8. <nav>

Defines navigation menu links.

<nav>
    <a href="#">Home</a>
</nav>

9. <aside>

Side content (sidebar, ads, related posts).

<aside>
    Sidebar content
</aside>

10. <figure> + <figcaption>

Used for images with captions.

<figure>
    <img src="image.jpg" alt="">
    <figcaption>Image caption</figcaption>
</figure>

11. <details> + <summary>

Expandable/collapsible content.

<details>
    <summary>Click to expand</summary>
    Hidden content
</details>
